# Learning Spatial Unit-Norm Latents with Riemannian Flow Matching

This repository contains the code, results, report, and slides for the SRUL course project. SRUL stands for **Spherical Riemannian Unit-Norm Latents**.

The encoder maps an image to a spatial grid of unit-norm latent tokens. The latent prior is trained with Riemannian Flow Matching, so the transport path and sampling updates remain on the product of spheres. The experiments study path matching, support matching, tangent-noise information control, classifier-free guidance, and transfer to PathMNIST and CelebA-64.

![SRUL pipeline](assets/srul_pipeline.png)

## Model architecture

- CNN encoder: `3 -> 96 -> 192 -> 384 -> 32`
- CIFAR-10 and PathMNIST latent grid: `32 x 4 x 4`
- CelebA-64 latent grid: `32 x 8 x 8`
- CNN decoder: `32 -> 384 -> 192 -> 96 -> 3`
- Conditional RFM prior: hidden width 256 with six residual blocks
- Time and class embedding: 128 dimensions
- Sampling: 100 tangent-projected exponential-map steps

## Installation

```bash
python -m pip install -r requirements.txt
```

Python 3.10 or later and a CUDA-enabled PyTorch installation are recommended.

## Checkpoints

**Trained `.pt`, `.pth`, and `.ckpt` files are not included in this repository.** They are large, remain in the experiment storage used for the reported runs, and are excluded by `.gitignore`.

Some launchers train from scratch. Others require a checkpoint generated by an earlier run. The table below shows the dependency chain.

| Launcher | Runs from scratch? | Required input |
|---|---:|---|
| `run_cifar10_geometry.sh` | Yes | none |
| `run_cifar10_conditional.sh` | No | CIFAR-10 spherical autoencoder checkpoint |
| `run_cifar10_sigma_sweep.sh` | No | CIFAR-10 spherical autoencoder checkpoint |
| `run_cifar10_matched_baselines.sh` | No | CIFAR-10 SRUL autoencoder and RFM checkpoints |
| `run_cifar10_vae_geometry.sh` | No | VAE checkpoint, VAE latent statistics, and baseline metrics CSV |
| `run_pathmnist.sh` | Yes | none |
| `run_celeba64.sh` | Yes | CelebA cache directory |
| `run_pathmnist_knob_cfg.sh` | No | PathMNIST spherical autoencoder checkpoint |
| `run_celeba64_knob_cfg.sh` | No | CelebA spherical autoencoder checkpoint and cache directory |
| `run_cifar10_spherical_coverage.sh` | No | CIFAR-10 spherical autoencoder checkpoint |

See [`docs/CHECKPOINTS.md`](docs/CHECKPOINTS.md) for the expected filenames and example paths.

## Typical workflow

### 1. CIFAR-10 geometry experiment

```bash
bash scripts/run_cifar10_geometry.sh runs
```

This creates, among other files:

```text
runs/cifar10_geometry/seed_0/checkpoints/autoencoder_final.pt
runs/cifar10_geometry/seed_0/checkpoints/rfm_final.pt
```

### 2. Conditional CIFAR-10 prior

```bash
bash scripts/run_cifar10_conditional.sh \
  runs \
  runs/cifar10_geometry/seed_0/checkpoints/autoencoder_final.pt
```

### 3. CIFAR-10 information-control sweep

```bash
bash scripts/run_cifar10_sigma_sweep.sh \
  runs \
  runs/cifar10_geometry/seed_0/checkpoints/autoencoder_final.pt
```

### 4. PathMNIST and CelebA-64

```bash
bash scripts/run_pathmnist.sh runs
bash scripts/run_celeba64.sh runs data/celeba64
```

After these finish, use their autoencoder checkpoints for the controlled noise/CFG sweeps:

```bash
bash scripts/run_pathmnist_knob_cfg.sh \
  runs \
  runs/pathmnist/seed_0/checkpoints/autoencoder_final.pt

bash scripts/run_celeba64_knob_cfg.sh \
  runs \
  runs/celeba64/seed_0/checkpoints/autoencoder_final.pt \
  data/celeba64
```

## Main reported results

### Path matching on spherical support

| Method | FID ↓ | Precision ↑ | Recall ↑ | Minimum token norm ↑ |
|---|---:|---:|---:|---:|
| Chord baseline | 67.44 | 0.840 | 0.085 | 0.705 |
| SRUL (geodesic RFM) | **63.84** | **0.857** | **0.091** | **1.000** |

### Support matching with the same VAE

| Method | FID ↓ | Precision ↑ | Recall ↑ |
|---|---:|---:|---:|
| SRUL | **49.42** | **0.857** | **0.110** |
| VAE + standard FM | 50.70 | 0.855 | 0.091 |
| VAE + projected RFM | 56.04 | 0.848 | 0.063 |

### Controlled information-noise sweep

CFG is fixed at `s = 2` while `sigma_enc` changes.

| Dataset | FID at 0.05 | FID at 0.15 | FID at 0.30 |
|---|---:|---:|---:|
| CIFAR-10 | **48.71** | 51.61 | 58.16 |
| PathMNIST | 29.88 | **29.35** | 34.33 |
| CelebA-64 | **37.68** | 41.10 | 55.21 |

### Controlled CFG sweep

`sigma_enc` is fixed at `0.15` while the guidance scale changes.

| Dataset | FID at 1.0 | FID at 1.5 | FID at 2.0 |
|---|---:|---:|---:|
| CIFAR-10 | 62.44 | 54.83 | **49.39** |
| PathMNIST | 29.16 | **28.17** | 29.35 |
| CelebA-64 | 41.13 | 41.15 | **41.10** |

The full result grids are in `results/`.
