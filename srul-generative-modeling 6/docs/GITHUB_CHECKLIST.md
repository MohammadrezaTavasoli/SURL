# GitHub submission checklist

- [ ] Create a new public or private repository.
- [ ] Upload the contents of this folder, not the outer ZIP folder.
- [ ] Confirm `README.md` renders correctly.
- [ ] Confirm `requirements.txt` installs in a clean Colab runtime.
- [ ] Run the smoke-test command from the README.
- [ ] Do not upload checkpoints, datasets, or Google Drive caches.
- [ ] Add the repository URL to the course submission.
- [ ] Keep the final report under `report/`.
- [ ] Keep the 5-slide deck under `slides/`.
- [ ] Review the CelebA license before redistributing any dataset images.
