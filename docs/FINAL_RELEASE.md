# Final release

This repository contains the final course-project materials for **SRUL: Spatial Spherical Latents with Riemannian Flow Matching**.

## Final deliverables

- `report/SRUL_Final_Report.pdf`: five pages of main content plus references.
- `report/SRUL_Final_Report.tex`: LaTeX source using the included `neurips.sty`.
- `slides/SRUL_Final_5_Slides.pptx`: five-slide presentation.
- `slides/SRUL_Final_5_Slides.pdf`: rendered presentation.
- `slides/SRUL_5min_Speaker_Script.md`: slide-by-slide script.

## Core implementation

The main experiments are in `src/`, with reproducible commands under `scripts/` and a Colab entry point under `notebooks/`.
