# Repository checklist

- [ ] Confirm that all Python files compile.
- [ ] Run the minimal validation cell in the Colab notebook.
- [ ] Check that the shell launchers pass `bash -n`.
- [ ] Keep datasets, caches, and model checkpoints out of Git history.
- [ ] Verify the checkpoint paths listed in `docs/CHECKPOINTS.md`.
- [ ] Keep the report under `report/` and the presentation under `slides/`.
- [ ] Confirm that the CSV files in `results/` match the report tables.
